# Drag-and-Drop Kanban Board

A feature-rich, drag-and-drop Kanban task management board built in React using native HTML5 drag-and-drop APIs.

## Features

- **3 Status Columns**: To Do, In Progress, and Done.
- **HTML5 Drag-and-Drop**: Drag task cards seamlessly between columns with visual highlight drop zones.
- **Task Management**: Add new tasks with custom title and priority level (Low, Medium, High).
- **Task Counter**: Live task count per column.
- **Fallback Mobile Controls**: Move left/right buttons for touch devices.
- **Task Deletion**: One-click task removal.
- **Persistent Data**: Automatically persists task state in `localStorage`.
- **Colored Columns**: Distinct visual themes per column status.

## Tech Stack

- **React** (Vite)
- **CSS3** (CSS Grid, flexbox, HTML5 drag styling)

## Quick Start

1. Copy `App.jsx` and `App.css` into your Vite React project.
2. Run `npm run dev`.
